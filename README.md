# Проект 2. Анализ воронки продаж и удержания когорт интернет-магазина

**Вопрос:** где магазин теряет пользователей на пути к покупке, на чём держится выручка и как возвращаются недельные когорты?

**Данные:** [REES46 eCommerce behavior data](https://www.kaggle.com/datasets/mkechinov/ecommerce-behavior-data-from-multi-category-store), файл `2019-Oct.csv` (октябрь 2019, около 42 млн событий `view` / `cart` / `purchase`). Файл в репозиторий не включён (несколько ГБ): скачайте его с Kaggle и положите в корень проекта.

**Стек:** Python, DuckDB (SQL), pandas, matplotlib. Следующий шаг: дашборд в Power BI на основе `export/`.

## Структура
```
project2/
├── project2_funnel_cohorts.ipynb   # анализ, графики, выводы
├── sql/                            # все запросы (00–15), ноутбук подгружает их из этой папки
├── export/                         # агрегированные CSV для Power BI (создаются ноутбуком)
├── requirements.txt
├── .gitignore
└── README.md
```

## Как запустить
1. `pip install -r requirements.txt`
2. Положить `2019-Oct.csv` в корень проекта (рядом с ноутбуком и папкой `sql/`).
3. Открыть ноутбук из папки проекта и выполнить `Restart & Run All`. Первый запуск создаёт `project2.db` и занимает несколько минут.

## Главные результаты
- Конверсия view → purchase **11.48%** (6.79% по сессиям); выручка на покупателя 662, примерный средний чек 365.
- **Electronics даёт около 77% выручки**; на **apple около 48%, на samsung около 20%**. У apparel / sport / accessories конверсия около 2% при малом вкладе в выручку.
- **Событию `cart` доверять нельзя**: 41.6% покупателей без корзины, у 10% она появилась после покупки. Доля покупателей без корзины скачкообразно меняется на границах режимов (около 42% и 63%; 4, 7, 14 и 28 октября), что похоже на смену записи корзины в системе, а не на поведение людей. Воронка построена без этого шага.
- **Главная потеря — отсутствие возврата**: на неделе 1 не возвращаются 65–79% когорты, а вернувшиеся покупают не реже. Тренд удержания между когортами оценить нельзя (смешанная первая когорта, один месяц данных).
- Около половины покупателей покупают в течение часа после первого просмотра, около четверти — позже чем через неделю.

## Определения и ограничения
Определения метрик, правила очистки, выводы, рекомендации и ограничения описаны в ноутбуке (разделы 1 и 8). Главное: один месяц данных, 32% событий без категории и 14% без бренда, заказ приравнен к сессии с покупкой, валюта в данных не указана, боты не фильтровались, время в UTC, выводы по брендам и одежде — гипотезы, рекомендации — гипотезы для проверки, а не доказанные причинно-следственные связи.
